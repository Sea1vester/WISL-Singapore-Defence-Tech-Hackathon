How to start a local server

Ollama: run ollama serve, then ollama pull qwen2.5:7b-instruct once if you need a model. Choose any installed instruction-following model.

LM Studio: load a model and start its local server; choose OpenAI-compatible and use the server URL it displays (usually port 1234). For llama.cpp, use its server port (often 8080) with /v1.

Connections originate from the WISL API, not your browser. For a remote assessment, run WISL beside your model or arrange a loopback SSH tunnel on the WISL host. Only loopback and Docker-host addresses are accepted. Server tokens stay in this page's memory and are sent only with authenticated requests; they are not saved.
